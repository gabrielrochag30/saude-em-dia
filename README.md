
# Saúde em Dia

O Saúde em Dia é um projeto acadêmico de desenvolvimento de software que tem como objetivo facilitar a organização das informações de pacientes e o acompanhamento de visitas domiciliares por Agentes Comunitários de Saúde (ACS).

## Objetivo

Desenvolver uma aplicação web simples que permita cadastrar, consultar e editar pacientes, além de registrar e agendar visitas domiciliares.

## Funcionalidades previstas

- Cadastro e consulta de pacientes.
- Edição de informações dos pacientes.
- Agendamento de visitas domiciliares.
- Registro de visitas realizadas.
- Consulta ao histórico de visitas.
- Identificação da última visita concluída.
- Autenticação de acesso.

## Tecnologias utilizadas

- Python
- Flask
- HTML5
- CSS3
- SQLite (previsto para a próxima etapa)

## Status do projeto

Em desenvolvimento. Atualmente, o projeto possui a estrutura inicial e as telas de login, pacientes e visitas. As funcionalidades de autenticação e persistência de dados ainda serão implementadas.

## Observação

Projeto acadêmico desenvolvido para fins de aprendizagem. Os dados utilizados no protótipo são fictícios.
